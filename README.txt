FALCON TRADER WEBSITE
======================

This is a free static e-commerce starter website for Falcon Trader.

Included:
- Premium navy/gold responsive design
- Product catalog
- Add to Cart
- Cart quantity controls
- Checkout form
- Cash on Delivery option
- Online Bank / Wallet Transfer option (manual; gateway not connected)
- Order confirmation
- Mobile-friendly layout
- Local cart persistence

IMPORTANT:
The product photos in this demo are placeholders. Replace the product cards/images with your real Falcon Trader product photos and prices.

For true automatic online payments, connect a supported Pakistan payment gateway/merchant account. A free static website alone cannot create a merchant account or process card/wallet payments automatically.

The checkout currently demonstrates the customer flow and creates a browser-side confirmation only; it does not yet send orders to a real admin database/email.
